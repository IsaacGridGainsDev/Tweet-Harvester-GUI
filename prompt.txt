### 📥 Functional Requirements (Implement via Functions/Classes)

#### 🟫 **Mining Layer (`mining/data_mining.py`)**
- A function to scrape tweets via `snscrape` based on a keyword and save to `tweets.json`.
- A streaming listener using `astream` to process live tweets with metadata.

#### 🟧 **Preprocessing Layer (`processing/preprocessing.py`)**
- Extract these attributes:  
  `text`, `created_at`, `lang`, `favorite_count`, `favorited`, `retweeted`, `id`, `place`, `user`, `entities`, `in_reply_to_user_id`, `in_reply_to_status_id`
- Tokenize tweets using NLTK.
- Apply a custom tokenizer that:
  - Removes stop words
  - Extracts unique terms and frequent terms
  - Uses `nltk.bigrams()` to extract paired terms.

#### 🟨 **Analytics Layer (`analytics/analysis.py`)**
- Compute most frequent terms.
- Build a **co-occurrence matrix** to track term pairings and semantic relationships.
- Implement **semantic orientation scoring**:
  - Given lists of positive and negative terms, calculate sentiment based on term proximity and co-occurrence likelihood.

#### 🟩 **Visualization Layer (`visualization/visualization.py`)**
- Use **Vincent** to create a D3.js-based bar chart of frequent terms.
- Use **Pandas** to generate a time series chart showing term frequency over time (minutes, hours, days).
- Use **Leaflet.js** (via `folium`) to plot tweet geolocations interactively on a map.

#### 🟦 **GUI Layer (`gui/gui.py`)**
- Build a CustomTkinter-based interface with:
  - Input for search keyword
  - Start/stop buttons for scraping and streaming
  - Dropdowns or checkboxes for NLP options (frequency, sentiment, map)
  - Panels to display charts and maps embedded inside the app
